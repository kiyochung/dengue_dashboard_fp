# Welcome to French Polynesia's Dengue Dashboard

This is an interactive R Shiny dashboard to explore **French Polynesia’s dengue surveillance**, access the latest **seroprevalence study results**, and explore a **short-term forecasting module** informed by surveillance and climate data. It also includes a **Links** tab providing access to external resources.

> **Disclaimer:** This app is an information-support and exploratory analysis tool—not a clinical diagnostic system. Model results are provided for exploratory purposes only. They describe plausible scenarios conditional on the underlying assumptions and selected parameters and should not be interpreted as precise forecasts. Real-world dynamics may differ due to data uncertainty, behavioral and environmental changes, and public health interventions.


## Features at a glance

### Dashboard Tabs

- **Surveillance data**
  - Epidemic curves by year (2013–2025)
  - Stratification (e.g., by serotype, age group, location)

- **Seroprevalence**
Provides the latest serosurvey results (study conducted by ILM's Research laboratory on Emerging viral infections)
  - Overall seroprevalence estimates
  - Stratification (e.g., by sex, age group, location)

- **Model**
  - Simple vectorial SEIR model to simulate dengue epidemic trajectories under user-defined assumptions
  - Upload surveillance case data (CSV/XLS/XLSX) to view the dataset, plot cases over time, and run short-term scenario-based simulations (exploratory; not precise forecasts)

- **Links**
  - Clickable links to external resources (e.g., Pacific Health Dashboard — Pacific Community; Nextstrain dengue)
  - Access links for documentation
